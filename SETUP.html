คู่มือติดตั้ง — Trading Signal Agent

4 ขั้นตอนหลัก · ใช้เวลารวมประมาณ 12 นาที · ไม่มีค่าใช้จ่าย · repo แบบ public + Cowork อ่านอัตโนมัติ (Discord เป็นตัวเสริม แยกไว้ท้ายเอกสาร)

ทำไมเปลี่ยนกลับมาเป็น public
รอบก่อนตั้งเป็น private เพื่อความเป็นส่วนตัว แต่ผลคือผม (Claude) อ่านไฟล์ผลสแกนไม่ได้เลย ต้องพึ่ง Discord อย่างเดียว ซึ่งเห็นผลช้าเพราะ v5.1 เทรดแค่ ~0.7-1 ครั้ง/เดือน
รอบนี้ตั้งเป็น public แทน — ผมอ่าน signals.json ได้ตรง ๆ ทุกครั้งที่สแกน แล้วสรุปเป็นภาษาคนส่งเข้าแชทให้ทันที เห็นได้ว่าระบบทำงานจริงตั้งแต่รอบแรก ไม่ต้องรอให้มีสัญญาณเทรดก่อน
ข้อแลกเปลี่ยนที่ต้องรู้ก่อนตัดสินใจ: public แปลว่าใครก็เห็น data/state.json ได้ — มีไม้ที่เปิดอยู่ ราคาเข้า/ออก และกำไร-ขาดทุนสะสม (คำนวณจากพอร์ตสมมติ 100 USDT ใน config ไม่ใช่ยอดเงินจริงในบัญชี) ไม่มีชื่อ ไม่มีข้อมูลบัญชี แต่เป็นสถิติการเทรดของคุณที่เปิดให้ทุกคนดูได้
ถ้าไม่สบายใจเรื่องนี้ บอกได้ทุกเมื่อ แล้วกลับไปใช้แบบ private + Discord อย่างเดียวได้เหมือนเดิม
1

สร้าง repo แบบ public 2 นาที

  1. ไปที่ github.com/new
  2. Repository name: agent-trade
  3. เลือก Public
  4. อย่าติ๊ก Add a README / .gitignore / license — โฟลเดอร์เรามีอยู่แล้ว ถ้าติ๊กจะชนกันตอน push
  5. กด Create repository
2

Push ขึ้น GitHub 3 นาที

เปิด Command Prompt หรือ PowerShell แล้วรันทีละบรรทัด:

cd /d "E:\agent tread\agent-trade"

git init
git add -A
git commit -m "Trading signal agent v0.5"
git branch -M main
git remote add origin https://github.com/Naxyz23/agent-trade.git
git push -u origin main

ครั้งแรกจะมีหน้าต่างให้ล็อกอิน GitHub ขึ้นมา ล็อกอินตามปกติ

ถ้าเจอ error นี้แปลว่า / แก้ยังไง
git is not recognizedยังไม่ได้ติดตั้ง Git → โหลดจาก git-scm.com กด Next รวด ๆ แล้วเปิด Command Prompt ใหม่
remote origin already existsเคยรัน git remote add ไปแล้ว → ใช้ git remote set-url origin https://github.com/Naxyz23/agent-trade.git แทน
failed to push some refsrepo ฝั่ง GitHub มีไฟล์อยู่แล้ว (เผลอติ๊ก README) → git pull --rebase origin main แล้ว push ใหม่
Authentication failedรหัสผ่านธรรมดาใช้ไม่ได้แล้ว → ต้องใช้ Personal Access Token หรือติดตั้ง GitHub CLI แล้ว gh auth login
3

รันครั้งแรกด้วยมือ 4 นาที

  1. เข้า repo บนเว็บ → แท็บ Actions
  2. ถ้าขึ้นถามว่าจะเปิด workflow ไหม กด I understand my workflows, go ahead and enable them
  3. เมนูซ้าย → daily-signals → ปุ่ม Run workflow (ขวามือ) → Run workflow
  4. รอ 2-3 นาที แล้วกดเข้าไปดูใน job ที่ชื่อ scan

4

บอกผมว่า push เสร็จแล้ว

กลับมาที่แชทนี้ พิมพ์ว่า "push เสร็จแล้ว" ผมจะ:

  1. ดึง signals.json มาดูจริง เพื่อยืนยันว่าอ่านได้
  2. ตั้ง Cowork scheduled task 2 รอบ (13:10 และ 04:10 น. ไทย ตรงกับที่ GitHub Actions สแกน)
  3. รอบแรกจะส่งสรุปเข้าแชทให้ดู ไม่ว่าจะมีสัญญาณหรือไม่ — ช่วงทดสอบนี้อยากให้เห็นว่า ระบบทำงานทุกรอบจริง ๆ ก่อน แล้วค่อยปรับให้เงียบเฉพาะตอนไม่มีสัญญาณทีหลัง

หลังติดตั้งเสร็จ — 2 สัปดาห์แรกควรทำอะไร

  • อย่าเพิ่งเทรดตาม โดยเฉพาะหุ้น US 13 ตัวที่ยังไม่เคยผ่าน backtest ของ v5.1
  • เปิด signals.json เทียบตัวเลข EMA20 / EMA200 / RSI14 กับ TradingView สัก 3-4 ตัว ถ้าตรงกัน แปลว่าชั้นข้อมูลเชื่อได้
  • ดูว่าสัญญาณที่ออกมา ตรงกับที่คุณจะเข้าเองไหม ถ้าไม่ตรง จดไว้ว่าต่างตรงไหน
  • เช็คว่า Action รันครบทุกวันไหม (แท็บ Actions จะมีจุดเขียวเรียงกัน)
  • พอมั่นใจแล้ว บอกผมให้เปลี่ยนโหมดสรุปจาก "ส่งทุกรอบ" เป็น "ส่งเฉพาะมีสัญญาณ" — กัน brief รกแชทตอนไม่มีอะไรเกิดขึ้น

ส่วนเสริม — เปิด Discord แจ้งเตือนด้วย ไม่บังคับ

ระบบมี Discord notify เตรียมไว้ในโค้ดอยู่แล้ว (engine/notify.py) ถ้าอยากได้แจ้งเตือน เด้งเข้ามือถือทันทีที่มีสัญญาณ โดยไม่ต้องรอ Cowork เปิดแอป ทำตามนี้เพิ่มได้:

  1. เปิด Discord บนคอมพิวเตอร์ → สร้างเซิร์ฟเวอร์/ห้อง signals ถ้ายังไม่มี
  2. เฟือง (Edit Channel) → Integrations → Webhooks → New Webhook → Copy Webhook URL
  3. อย่าวาง URL นี้ลงในแชทนี้ — ใครได้ไปก็โพสต์เข้าห้องคุณได้ ถ้าเผลอหลุดไปแล้ว กลับไปกด Delete Webhook สร้างใหม่ได้ทันที
  4. ทดสอบด้วย PowerShell (แทน URL ของจริงในบรรทัดแรก): 
    $hook = "วาง_URL_ที่นี่"
Invoke-RestMethod -Uri $hook -Method Post -ContentType "application/json" -Body '{"content":"test"}'
    เงียบ = สำเร็จ เช็คที่ห้อง Discord ว่ามีคำว่า test เด้งขึ้น
  5. เข้า repo → Settings → Secrets and variables → Actions → New repository secret
    Name: DISCORD_WEBHOOK (ตัวใหญ่ทั้งหมด ต้องตรงเป๊ะ) · Secret: วาง URL
  6. รัน workflow ใหม่ 1 ครั้ง — รอบต่อไปที่มีสัญญาณ entry/exit จะเด้งเข้า Discord ทันที (ค่าเริ่มต้นส่งเฉพาะวันที่มีสัญญาณจริง ปรับได้ที่ notify.on_empty ใน watchlist.yml)
